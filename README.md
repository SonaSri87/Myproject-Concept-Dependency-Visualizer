# Concept Dependency Visualizer

## Overview

Concept Dependency Visualizer is a web application that helps learners understand concept prerequisites and generate personalized learning paths.

The application uses graph-based traversal techniques to determine the optimal order for learning concepts.

---

## Features

- Learning Path Generator
- Concept Dependency Visualization
- Knowledge Gap Analysis
- Concept Search
- Concept Details Viewer
- Optimal Learning Order
- Progress Tracking
- Learning Analytics
- Achievement Badges
- Weekly Goal Tracker
- Learning Timeline
- Learning Report Export
- Dark / Light Theme
- Certificate Generation
